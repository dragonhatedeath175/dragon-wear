# DRAGON WEAR

This package contains the latest uploaded DRAGON WEAR website file packaged as a Render-ready Node/Express project.

## Structure
- `public/index.html` — the latest uploaded website
- `server.js` — Express server
- `package.json` — Node dependencies and start script
- `render.yaml` — Render deployment configuration
- `.env.example` — environment-variable example

## Run locally
```bash
npm install
npm start
```
Then open `http://localhost:3000`.

## Deploy to Render
Use build command `npm install` and start command `npm start`.
